Thème WordPress classique conçu pour l'accessibilité (RGAA 4.1 / WCAG 2.1 AA), au design moderne.

== Description ==

Neodyr Access est un thème classique pensé pour l'accessibilité de bout en bout, sans rien sacrifier au design. Structure sémantique, navigation clavier (menus déroulants à deux niveaux inclus), contrastes conformes, formulaires et commentaires accessibles.

Fonctionnalités :

* Palettes de couleurs personnalisables et garanties AA (vert, bleu, ardoise).
* Bannière d'accueil, blocs de mise en avant et bande d'appel à l'action configurables.
* Menus déroulants à deux niveaux, pilotables au clavier (aria-expanded, Échap).
* Pied de page en colonnes avec zones de widgets.
* Composants prêts à l'emploi : cartes, chiffres clés, encarts, badges, étapes.
* Polices auto-hébergées (aucune requête vers un service tiers).

== Installation ==

1. Dans l'administration, allez dans Apparence > Thèmes > Ajouter.
2. Téléversez l'archive du thème, puis activez-le.
3. Personnalisez couleurs, mise en page et accueil via Apparence > Personnaliser.

== Frequently Asked Questions ==

= Le thème est-il vraiment accessible ? =

Oui. Il vise la conformité RGAA 4.1 / WCAG 2.1 AA : contrastes vérifiés, navigation clavier, repères ARIA, focus visible, formulaires étiquetés.

= Peut-on choisir librement les couleurs ? =

Le thème propose des palettes pré-validées (contraste AA garanti) plutôt qu'une saisie libre, afin de préserver la conformité quel que soit le choix.
